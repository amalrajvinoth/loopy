# What's new in loopy

The big changes, newest first. Small fixes are not listed.

| Date | What's new | Where | PR |
| --- | --- | --- | --- |
| 2026-10-16 | New game for ages 10 to 16: Equation Balance (German: Waage). A see-saw shows two sides of an equation; find x so it is level. It starts with a missing number (□ + 4 = 9) and grows to x on both sides. A wrong answer tips the see-saw and shows the steps. Read aloud and a printable worksheet, in English and German. | Home page (Math), Equation Balance | #64 |
| 2026-10-16 | See who is playing: the child's picture and name now sit next to Settings in every game and Today's 10, even with only one child. Tap it to change the name or picture. With no name yet, just the picture shows. On small phones the back button shows only its arrow to make room. | Home page, every game, Today's 10 | |
| 2026-10-16 | One child to start: a new device shows no list of names. Add brothers and sisters in Settings (Kids); the "Who is playing?" row only shows with two or more. Each child's last game, levels and settings are kept, and the home page offers "Carry on". Stars are kept in a bigger browser store, and loopy asks the browser not to clear them. Move one child or everyone to another device with a code or a link, which asks before loading. Devices with Dio and Dia keep them, and old codes still work. | Home page (Settings, Carry on, Move my stars), every game | #54 |
| 2026-10-16 | Report a problem from inside a game: tap the small flag at the top (or Report a problem in Settings) when a question or answer is wrong, or something looks wrong. loopy makes a picture of the screen to save, and opens a GitHub form with the details filled in. Nothing is sent until a grown-up sends it. English and German. | Every game, Today's 10, Help | #51 |
| 2026-10-16 | Easier for young kids: the home page shows each game as a big picture tile, games first and My stars below. Before answering there is a small "Skip" instead of a big button that skipped by mistake; after answering, a big "Next" in every game. The score row is one line (Last 5 and a 🔥 streak). A "+1 ⭐" flies to the star counter after each right answer. The first time a child opens a game, a bubble shows what to tap. Settings look the same in every game. The reason after an answer always fits in the card. | Home page, every game | #50 |
| 2026-10-15 | Works with a keyboard and a screen reader: a clear focus ring on every button in every theme, right and wrong answers read out, Escape closes Settings, and after Next the keyboard lands on the new problem. Continents on the map are one stop each. | Every page | #46 |
| 2026-10-15 | Easier to see and read: a High contrast color theme (black and white, bright colors, white edges on every button), and an "Easier to read" font switch with clearer letter shapes. Both in Settings, in English and German, and remembered on this device. | Every page | #45 |
| 2026-10-15 | More than one child: brothers and sisters can share one device. Add a child with a name, a picture and an age, and tap a name to switch. Each child has their own stars, badges, streaks, age, progress and game settings. A new device starts with Dio and Dia. Stars already earned go to Dio. The stars code holds every child, and each one lands on the child with the same name. | Home page (Who is playing?), every game, How it's going | #17 |
| 2026-10-15 | Bigger stars code: moving to a new phone or tablet now keeps the day streak, the answers on the grown-ups' page, the Last 5 dots, the age and the settings, not just stars. The code is packed small so it still copies in one tap. Loading a code only adds, and old codes still work. | Home (Move my stars), How it's going | #42 |
| 2026-10-15 | Works offline: after one visit with internet, loopy opens with no internet too. Every game, Today's 10, Help and the grown-ups' page work on a plane or in the car. New versions arrive by themselves the next time you are online. | Every page | #43 |
| 2026-10-15 | Where Is It?, the first geography game: tap continents, oceans, countries and capitals on a map. Europe first, then the whole world, one region at a time. Read aloud and a printable worksheet. English and German. | Where Is It? (new game), How it's going | #41 |
| 2026-10-15 | Quick Facts, the first science game: short picture quizzes about space, animals and the body, with one line of why after each answer.
