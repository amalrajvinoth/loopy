# Update the roadmap

1. Read issue #21, every open issue, and the pull requests merged since #21 was last edited.
2. Tick what has merged (with its PR number), keep the order of what is open, and add new issues where the owner asked for them (a "priority" label goes first as "Next").
3. Keep the issue's own format and plain words. Edit the issue body; do not post a comment unless the owner asked.
4. Reply in one or two lines: what moved and what is next.
