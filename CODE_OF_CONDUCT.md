# Code of conduct

Loopy is for kids, so we keep this space kind and safe.

## Please do

- Be kind and patient.
- Respect other people and their ideas.
- Give helpful feedback, not harsh words.
- Keep everything suitable for children.

## Please do not

- Share personal details about any child, like a name, photo, school or location.
- Post rude, hateful, scary or adult content.
- Bully, harass or threaten anyone.
- Post spam or ads.

## What happens if someone breaks these rules

The owner may edit or delete posts, lock threads, or block people from the project.

## How to report something

Use the **Report** option on the post (the `...` menu on GitHub), or contact the owner through their GitHub profile: https://github.com/amalrajvinoth

This code is based on the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.
