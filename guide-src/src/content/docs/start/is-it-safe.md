loopy keeps your stars on your device. Nobody else can see them.

This page is for grown-ups. It says in plain words what loopy keeps, and where.

## Nothing is sent

- There are no accounts. Nobody signs up or logs in.
- There are no ads, no tracking and no analytics.
- loopy uses no outside services. Even the fonts are stored on the loopy site, so the browser only talks to loopy.

## Where the data lives

Stars, badges, settings, children's names and the answers on the grown-ups' page are saved in this browser, on this device. They are saved twice, in two stores in the browser. If one is cleared, loopy brings it back from the other. See [Where stars live](/loopy/guide/stars/where-stars-live/).

A child's name is plain text, at most 12 letters. A nickname is fine. Pictures come from a fixed list of animals.

To move stars to another device, loopy makes a code, a link or a QR code on your device. The stars are in the link itself, after the `#`. That part of a link never reaches the website. See [Move stars](/loopy/guide/stars/move-stars/).

## Strict security rules

Every page tells the browser three things:

1. Only load files from loopy itself.
2. Never send data to other websites.
3. Only run loopy's own code. Anything added from outside is blocked.

The games use no outside code. This guide is made with free tools (Astro and Starlight), and every file it needs is stored on the loopy site too. See [Security](/loopy/guide/help/security/).

## The 🚩 Report a problem flag

The small flag at the top of a game is for a wrong question or answer, or something that looks wrong. Nothing is sent by itself.

1. Tap the flag and pick what is wrong.
2. loopy makes a picture of the screen on your device. You can tap **Save picture**.
3. **Open GitHub** opens a form in a new tab. The details are filled in: the game, what was on the screen, the last answer, the age, the language, the theme, the screen size and the browser.
4. Nothing goes anywhere until a grown-up sends that form on GitHub.

The child's name is never in it. GitHub is public and for ages 13 and up, so a grown-up should send it. See [Report a problem](/loopy/guide/help/report-a-problem/).
