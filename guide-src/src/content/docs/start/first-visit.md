The first time loopy opens in a browser, it asks three small things. Everything can be skipped, and it never asks again.

## 1. Hi! Who is playing?

Type the child's name or nickname, pick a picture and set the age with **−** and **+**. Tap **Next**. loopy keeps one child per device until you add more in ⚙ Settings. **Skip** keeps the 🐰 with no name, and you can do all of it later under [Kids and ages](/loopy/guide/setup/kids-and-ages/).

## 2. For grown-ups: keep the stars on every device

This step is for a parent. A family code keeps the stars the same on the phone, the tablet and the computer. Nothing is sent until you tap a button.

- **Make a family code** turns on [Family sync](/loopy/guide/stars/family-sync/) and shows the code with its QR code right there. Scan it with the other device, or tap **Share the link** to send it.
- **I already have a code** is for a second device. Type the code from the first device and tap **Join**. The family's stars come over.
- **Later** moves on. Nothing changes.

## 3. All set!

Tap **Let's play!** and the games are there. The name and picture show in the top row.

## The family code row

As long as no family code is set, the home page shows a short row under **My stars**: "Keep the stars on every device". It has **Turn on**, **Join with a code** and **Not now**. **Turn on** makes the code right there, like step 2. **Not now** hides the row for the rest of the day. Once a code is set, the row is gone. A device that already has stars never sees the welcome, only the row.

## Good to know

- The welcome shows once per browser. Clearing the browser's site data brings it back, because it starts loopy afresh.
- On an iPhone, iPad or Mac, loopy added to the home screen is its own browser, so it shows the welcome once more. **I already have a code** is the quickest way to bring the stars across.
- A German phone or browser starts loopy in German. Tap **EN** or **DE** to pick, and that choice stays.
- Nothing about the child leaves the device, and the family code never does. See [Is it safe?](/loopy/guide/start/is-it-safe/).
