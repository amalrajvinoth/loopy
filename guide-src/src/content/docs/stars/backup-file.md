Save your stars in a file. Then they are safe, even if the phone is lost.

A backup file keeps a copy of the stars outside the browser. It survives a lost phone or cleared browser data, and you can open it on any device.

## Save backup

1. On the home page, scroll down to **My stars**.
2. Open **Move my stars to another device**.
3. With two or more children, pick **Everyone** or one child.
4. Tap **Save backup**.

loopy makes a small file named like `loopy-stars-2026-10-19.json`, with the day's date. It is made on your device. The message says: "Backup file made. Find it in Downloads or Files, and keep it in iCloud Drive or Google Drive."

## Where the file lands

- **iPhone and iPad:** in the Files app, in Downloads.
- **Android:** in Downloads.
- **Computer:** in the Downloads folder.

## Keep it safe

A file in Downloads goes away with the phone. Move it to iCloud Drive or Google Drive, so it is safe in the cloud. Make a new backup now and then, because the file only holds the stars from the day it was made.

The file holds the children's names, stars and progress. Keep it private, like a photo.

## Open backup

1. On any device, open loopy and go to **Move my stars to another device**.
2. Tap **Open backup**.
3. Pick the file.
4. loopy asks "Load Mia's stars here?". Tap **Load**.

Opening a backup only adds. Nothing on the device is taken away. See [Move my stars](/loopy/guide/stars/move-stars/).

If the file is not a loopy backup, it says "That file didn't work. Pick a loopy backup file."
