Ist eine Aufgabe falsch? Tippe auf die 🚩 Fahne. Dann hilft dir ein Erwachsener.

<Shot name="report" alt="Das Feld Problem melden mit drei Antworten, einer Notiz und einem Bild vom Bildschirm" />

Meldungen gehen an die Seite von loopy auf GitHub, einer anderen Website (auf Englisch). Alles dort ist öffentlich. GitHub-Konten gibt es ab 13 Jahren, darum sollte ein Erwachsener senden. Schreib nie den Namen eines Kindes oder andere persönliche Daten.

## Die 🚩 Fahne im Spiel

Jedes Spiel hat oben eine kleine 🚩 Fahne, neben ⚙ Einstellungen. Auf einem schmalen Bildschirm kann sie fehlen. Nimm dann **Problem melden** in den ⚙ Einstellungen. Das macht das Gleiche.

1. Tippe auf die 🚩 Fahne.
2. Wähle, was falsch ist: **Die Aufgabe ist falsch**, **Die Lösung scheint falsch** oder **Etwas sieht falsch aus**.
3. Schreib bei "Noch etwas? (freiwillig)" eine Notiz, wenn du magst. Zum Beispiel: "7 + 5 ist 12".
4. loopy macht ein Bild vom Bildschirm. Tippe auf **Bild speichern**. Manche Browser können das nicht. Mach dann ein Bildschirmfoto mit den Tasten deines Geräts.
5. Tippe auf **GitHub öffnen**. Ein Formular öffnet sich in einem neuen Tab, in dem alles schon steht.
6. Füg das Bild hinzu, prüf alles und schick es ab.

Nichts wird von selbst gesendet. Nichts verlässt dein Gerät, bis du das Formular auf GitHub abschickst. **Text kopieren** kopiert die Angaben, wenn du sie lieber selbst einfügst.

Die Angaben sind: das gewählte Problem, das Spiel, was auf dem Bildschirm stand, die letzte Antwort, Alter, Sprache, Farbthema, Leichter lesen, Bildschirmgröße, Browser und die loopy-Version. Der Name des Kindes steht nie darin.

## Die Hilfe-Seite

Tippe unten auf der Startseite auf **Hilfe und Feedback**. Unter "Sag uns deine Meinung" stehen vier Links:

- **Fehler melden:** Etwas geht nicht oder ist falsch. Es öffnet ein GitHub-Formular.
- **Idee teilen:** ein neues Spiel, Fach oder eine Funktion.
- **Frage stellen:** etwas, das die Hilfe-Seite nicht beantwortet.
- **Alle Beiträge:** Lies, was andere geschrieben haben.

## Auf GitHub

Fehler kommen in GitHub-**Issues**. Es gibt zwei Formulare:

- [Report a game problem](https://github.com/amalrajvinoth/loopy/issues/new?template=game-report.yml): das Formular, das die 🚩 Fahne ausfüllt.
- [Report a problem](https://github.com/amalrajvinoth/loopy/issues/new?template=problem.yml): für alles andere. Es fragt, wo es passiert ist, was schiefging, das Gerät, den Browser und die Sprache.

Ideen und Fragen kommen in GitHub-**Discussions**:

- [Idee teilen](https://github.com/amalrajvinoth/loopy/discussions/new?category=ideas)
- [Frage stellen](https://github.com/amalrajvinoth/loopy/discussions/new?category=q-a)
- [Alle Beiträge](https://github.com/amalrajvinoth/loopy/discussions)

Ein Sicherheitsproblem gehört nicht hierher. Mehr unter [Sicherheit](/loopy/guide/de/help/security/).
