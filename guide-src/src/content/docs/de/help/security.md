Etwas ist nicht sicher? Sag es einem Erwachsenen. Behalte es erst mal für dich.

Wenn du ein Sicherheitsproblem in loopy findest, melde es bitte privat. **Poste es nicht in einem öffentlichen Issue oder einer Diskussion.**

## Privat melden

1. Öffne [die Sicherheitsseite von loopy auf GitHub](https://github.com/amalrajvinoth/loopy/security/advisories/new). Du brauchst ein GitHub-Konto.
2. Schreib, was das Problem ist.
3. Schreib, wo es ist: welche Seite oder Datei.
4. Schreib Schritt für Schritt, wie man es sieht.
5. Schick es ab.

Nur der Besitzer kann deine Meldung sehen. Eine Antwort soll innerhalb von 7 Tagen kommen. Du erfährst, wenn es behoben ist, und wirst mit Namen bedankt, wenn du willst.

Den gleichen Link gibt es auf der Hilfe-Seite von loopy, unter **Sicherheitsproblem melden**.

## Was loopy für die Sicherheit tut

- **Keine persönlichen Daten.** Keine Konten, keine Werbung, kein Tracking, keine Analyse. Sterne und Einstellungen bleiben auf deinem Gerät.
- **Nichts von anderen Seiten.** Schriften und alle Dateien kommen von der loopy-Seite selbst. Die Seite sendet nie Daten.
- **Eine strenge Sicherheitsregel.** Jede Seite sagt dem Browser, nur Dateien von loopy zu laden und nur ihren eigenen Code auszuführen.
- **Kein fremder Code.** loopy nutzt keine Bibliotheken oder Pakete.
- **Geprüfte Daten.** Gespeicherte Einstellungen und Sterne-Codes werden vor der Nutzung geprüft. Nichts in einem Code wird je ausgeführt. Namen von Kindern sind reiner Text, höchstens 12 Buchstaben.
- **Nur HTTPS.** Die Seite kommt immer über eine sichere Verbindung.
- **Geprüfte Änderungen.** Der Besitzer prüft jede Änderung, bevor sie live geht.

Unterstützt wird nur die Live-Seite. Mehr steht in [SECURITY.md](https://github.com/amalrajvinoth/loopy/blob/main/SECURITY.md) (auf Englisch).
