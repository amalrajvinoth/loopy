Wenn loopy zum ersten Mal in einem Browser aufgeht, fragt es drei kleine Dinge. Alles lässt sich überspringen, und es fragt nie wieder.

## 1. Hallo! Wer spielt?

Tippe den Namen oder Spitznamen des Kindes ein, wähle ein Bild und stelle das Alter mit **−** und **+** ein. Tippe auf **Weiter**. loopy hat ein Kind pro Gerät, bis du in den ⚙ Einstellungen mehr hinzufügst. **Überspringen** lässt den 🐰 ohne Namen, und alles geht später unter [Kinder und Alter](/loopy/guide/de/setup/kids-and-ages/).

## 2. Für Erwachsene: Sterne auf allen Geräten behalten

Dieser Schritt ist für Eltern. Ein Familien-Code hält die Sterne auf Handy, Tablet und Computer gleich. Nichts wird gesendet, bis du auf einen Knopf tippst.

- **Familien-Code erstellen** schaltet den [Familien-Sync](/loopy/guide/de/stars/family-sync/) ein und zeigt den Code mit seinem QR-Code gleich dort. Scanne ihn mit dem anderen Gerät, oder tippe auf **Link teilen**, um ihn zu schicken.
- **Ich habe schon einen Code** ist für ein zweites Gerät. Tippe den Code vom ersten Gerät ein und dann auf **Beitreten**. Die Sterne der Familie kommen herüber.
- **Später** geht weiter. Nichts ändert sich.

## 3. Alles bereit!

Tippe auf **Los geht's!**, und die Spiele sind da. Name und Bild stehen in der obersten Zeile.

## Die Familien-Code-Zeile

Solange kein Familien-Code gesetzt ist, zeigt die Startseite eine kurze Zeile unter **Meine Sterne**: „Sterne auf allen Geräten behalten“ mit **Einschalten**, **Mit Code beitreten** und **Nicht jetzt**. **Einschalten** erstellt den Code gleich dort, wie in Schritt 2. **Nicht jetzt** blendet die Zeile für den Rest des Tages aus. Sobald ein Code gesetzt ist, ist die Zeile weg. Ein Gerät, das schon Sterne hat, sieht die Begrüßung nie, nur die Zeile.

## Gut zu wissen

- Die Begrüßung kommt einmal pro Browser. Wer die Website-Daten des Browsers löscht, sieht sie wieder, weil loopy dann von vorn beginnt.
- Auf iPhone, iPad oder Mac ist loopy auf dem Home-Bildschirm ein eigener Browser, darum zeigt es die Begrüßung noch einmal. **Ich habe schon einen Code** ist der schnellste Weg, die Sterne mitzunehmen.
- Ein deutsches Handy oder ein deutscher Browser startet loopy auf Deutsch. Tippe auf **EN** oder **DE**, um zu wählen, und die Wahl bleibt.
- Nichts über das Kind verlässt das Gerät, und der Familien-Code nie. Siehe [Ist es sicher?](/loopy/guide/de/start/is-it-safe/).
