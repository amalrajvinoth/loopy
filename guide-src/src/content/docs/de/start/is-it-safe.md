loopy speichert deine Sterne auf deinem Gerät. Niemand sonst kann sie sehen.

Diese Seite ist für Erwachsene. Sie sagt in einfachen Worten, was loopy speichert und wo.

## Nichts wird gesendet

- Es gibt keine Konten. Niemand meldet sich an.
- Es gibt keine Werbung, kein Tracking und keine Analyse.
- loopy nutzt keine fremden Dienste. Sogar die Schriften liegen auf der loopy-Seite. Der Browser spricht also nur mit loopy.
- Die einzige Ausnahme ist der [Familien-Sync](/loopy/guide/de/stars/family-sync/), und nur, wenn ein Erwachsener ihn einschaltet. Er sendet eine Kopie der Sterne, vorher auf deinem Gerät verschlossen, sodass der Server sie nicht lesen kann.

## Wo die Daten liegen

Sterne, Abzeichen, Einstellungen, die Namen der Kinder und die Antworten auf der Seite für Eltern werden in diesem Browser auf diesem Gerät gespeichert. Sie liegen doppelt da, in zwei Speichern im Browser. Wird einer gelöscht, holt loopy sie aus dem anderen zurück. Siehe [Wo die Sterne liegen](/loopy/guide/de/stars/where-stars-live/).

Der Name eines Kindes ist reiner Text, höchstens 12 Zeichen. Ein Spitzname reicht. Die Bilder kommen aus einer festen Liste mit Tieren.

Um Sterne auf ein anderes Gerät zu bringen, macht loopy auf deinem Gerät einen Code, einen Link oder einen QR-Code. Die Sterne stehen im Link selbst, nach dem `#`. Dieser Teil eines Links kommt nie bei der Website an. Siehe [Sterne umziehen](/loopy/guide/de/stars/move-stars/).

## Strenge Sicherheitsregeln

Jede Seite sagt dem Browser drei Dinge:

1. Lade nur Dateien von loopy selbst.
2. Sende nie Daten an andere Websites.
3. Führe nur den eigenen Code von loopy aus. Alles, was von außen dazukommt, wird blockiert.

Die Spiele nutzen keinen fremden Code. Diese Anleitung ist mit freien Werkzeugen gemacht (Astro und Starlight), und jede Datei, die sie braucht, liegt auch auf der loopy-Seite. Siehe [Sicherheit](/loopy/guide/de/help/security/).

## Die Flagge 🚩 Problem melden

Die kleine Flagge oben im Spiel ist für eine falsche Aufgabe oder Lösung, oder wenn etwas falsch aussieht. Von selbst wird nichts gesendet.

1. Tippe auf die Flagge und wähle, was falsch ist.
2. loopy macht auf deinem Gerät ein Bild vom Bildschirm. Du kannst auf **Bild speichern** tippen.
3. **GitHub öffnen** öffnet ein Formular in einem neuen Tab. Die Angaben sind schon eingetragen: das Spiel, was auf dem Bildschirm war, die letzte Antwort, das Alter, die Sprache, das Farbthema, die Bildschirmgröße und der Browser.
4. Nichts geht irgendwohin, bis ein Erwachsener das Formular auf GitHub sendet.

Der Name des Kindes steht nie darin. GitHub ist öffentlich und ab 13 Jahren, darum sollte ein Erwachsener es senden. Siehe [Problem melden](/loopy/guide/de/help/report-a-problem/).
