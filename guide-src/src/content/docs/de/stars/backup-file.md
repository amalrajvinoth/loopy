Speichere deine Sterne in einer Datei. Dann sind sie sicher, auch wenn das Handy weg ist.

Eine Sicherungsdatei hält eine Kopie der Sterne außerhalb des Browsers. Sie übersteht ein verlorenes Handy oder gelöschte Browserdaten, und du kannst sie auf jedem Gerät öffnen.

## Sicherung speichern

1. Scroll auf der Startseite nach unten zu **Meine Sterne**.
2. Öffne **Sterne auf ein anderes Gerät bringen**.
3. Ab zwei Kindern wähle **Alle** oder ein Kind.
4. Tippe auf **Sicherung speichern**.

loopy macht eine kleine Datei mit dem Datum im Namen, zum Beispiel `loopy-stars-2026-10-19.json`. Sie entsteht auf deinem Gerät. Die Meldung sagt: "Sicherungsdatei erstellt. Du findest sie unter Downloads oder Dateien. Bewahre sie in iCloud Drive oder Google Drive auf."

## Wo die Datei landet

- **iPhone und iPad:** in der App Dateien, unter Downloads.
- **Android:** unter Downloads.
- **Computer:** im Ordner Downloads.

## Gut aufbewahren

Eine Datei unter Downloads geht mit dem Handy verloren. Leg sie in iCloud Drive oder Google Drive, dann ist sie in der Cloud sicher. Mach ab und zu eine neue Sicherung, denn die Datei hat nur die Sterne vom Tag, an dem sie gemacht wurde.

Die Datei enthält die Namen, Sterne und den Fortschritt der Kinder. Halte sie privat, wie ein Foto.

## Sicherung öffnen

1. Öffne loopy auf einem beliebigen Gerät und geh zu **Sterne auf ein anderes Gerät bringen**.
2. Tippe auf **Sicherung öffnen**.
3. Wähle die Datei.
4. loopy fragt "Die Sterne von Mia hier laden?". Tippe auf **Laden**.

Eine Sicherung öffnen fügt nur hinzu. Auf dem Gerät geht nichts verloren. Mehr unter [Sterne auf ein anderes Gerät bringen](/loopy/guide/de/stars/move-stars/).

Ist die Datei keine loopy-Sicherung, steht dort: "Die Datei hat nicht geklappt. Wähle eine loopy-Sicherungsdatei."
