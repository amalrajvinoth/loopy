Ein neues Tablet? Nimm deine Sterne mit!

<Shot name="move-stars" alt="Sterne auf ein anderes Gerät bringen, mit QR-Code, Link kopieren und dem Code" />

Es gibt kein Konto, also ziehen die Sterne mit einem Code um. Der Code enthält die Sterne und den ganzen Fortschritt. Du kannst ihn scannen, als Link schicken oder kopieren.

## Den Code machen

1. Scroll auf der Startseite nach unten zu **Meine Sterne**.
2. Öffne **Sterne auf ein anderes Gerät bringen**.
3. Ab zwei Kindern wähle unter "Wessen Sterne?" **Alle** oder ein Kind.

## Ihn umziehen

Wähle einen Weg:

- **Scannen:** Richte die Kamera des anderen Geräts auf den QR-Code. Dort öffnet sich loopy.
- **Senden:** Teile den Link über WhatsApp, AirDrop oder Mail. Diesen Knopf gibt es nur, wenn der Browser ein Teilen-Menü hat.
- **Link kopieren:** Kopiere den Link und öffne ihn auf dem anderen Gerät.
- **Code kopieren:** Tippe auf **Kopieren**. Öffne auf dem anderen Gerät das gleiche Feld, füge den Code bei "Code hier einfügen" ein und tippe auf **Laden**.

Ein Link fragt zuerst: "Die Sterne von Mia hier laden?". Tippe auf **Laden** oder **Nicht jetzt**.

Der Link trägt die Sterne hinter dem `#`. Dieser Teil eines Links kommt nie bei der Website an, also wird nichts gesendet. Auch der QR-Code wird auf deinem Gerät gezeichnet.

## Was umzieht

Sterne, Abzeichen, beste Ergebnisse, die Tage hintereinander, Letzte 5, das Alter, die Stufen und Einstellungen in den Spielen, die Antworten auf der Seite für Erwachsene, die Liste für Nochmal versuchen und das letzte Spiel, damit **Weiterspielen** auch dort geht. Namen und Bilder der Kinder ziehen mit um.

In einen QR-Code passt nur so viel. Bei viel Fortschritt lässt der QR-Code zuerst die Liste der falschen Antworten weg. Ist das immer noch zu viel, behält er nur Sterne, Abzeichen, Tagesserie, Alter, Level und Einstellungen der Spiele und das letzte Spiel. Die Zeile unter dem QR-Code sagt, was er enthält. Bei sehr vielen Kindern und Einstellungen gibt es kein Bild, und die Zeile sagt das. **Senden** und **Link kopieren** bringen immer alles mit.

## Laden fügt nur hinzu

Laden nimmt nie etwas weg. Die größere Zahl gewinnt, und zweimal den gleichen Code laden zählt nichts doppelt. Farbe, Schrift, Ton und Sprache werden nur übernommen, wenn auf dem anderen Gerät noch nichts gewählt ist.

Jedes Kind kommt zum Kind mit dem gleichen Namen, sonst kommt ein neues Kind dazu. Auf einem neuen Gerät nimmt das erste Kind den Platz des leeren ein.

## Was nicht umzieht

Der Code ist eine Kopie, keine feste Verbindung. Sterne, die später auf einem Gerät dazukommen, erscheinen nicht von selbst auf dem anderen. Zieh sie bei Bedarf noch einmal um. Alte Codes von früher laden noch, bringen aber nur Sterne und beste Ergebnisse mit.

Um den Code in einer Datei aufzubewahren, siehe [Sicherungsdatei](/loopy/guide/de/stars/backup-file/).
