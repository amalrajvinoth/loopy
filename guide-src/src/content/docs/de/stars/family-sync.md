Auf dem Tablet spielen, auf dem Handy weitermachen. Der Familien-Sync hält die Sterne auf allen Geräten deiner Familie gleich.

Er ist aus, bis ein Erwachsener ihn einschaltet. Dann läuft er von selbst: keine Codes kopieren, keine Dateien speichern.

## Einschalten

1. Öffne auf der Startseite ⚙ **Einstellungen**.
2. Scroll zu **Familien-Sync**.
3. Tippe auf **Einschalten**.

loopy zeigt euren Familien-Code, zum Beispiel `7K2M-QX9D-4HPT-W3RA`, und einen QR-Code.

## Ein weiteres Gerät dazunehmen

Auf dem anderen Handy, Tablet oder Computer:

- **Scanne den QR-Code** mit der Kamera. loopy öffnet sich und fragt "Dieser Familie beitreten?". Tippe auf **Beitreten**.
- **Oder tippe den Code ein:** Öffne ⚙ **Einstellungen**, dann **Familien-Sync**, dann **Mit Code beitreten**. Tippe den Code ein und dann auf **Beitreten**.

Die Sterne von den anderen Geräten kommen hierher, und die Sterne von hier kommen dorthin. Nichts geht verloren: Für jedes Kind gewinnt die größere Zahl, wie bei einem [Sterne-Code](/loopy/guide/de/stars/move-stars/).

Jedes Kind behält seine eigenen Sterne. Gib jedem Kind auf jedem Gerät denselben Namen, damit loopy weiß, wer wer ist. Groß- und Kleinschreibung ist egal. Ein Kind, das auf dem anderen Gerät noch fehlt, wird dort angelegt. Auf einem ganz neuen Gerät mit einem Kind ohne Namen nimmt das erste Kind der Familie diesen Platz.

Das andere Gerät darf schon eigene Sterne haben. Das ist in Ordnung. Beim Beitreten kommt beides zusammen, und nichts geht verloren. Die Startseite lädt einmal neu und zeigt dann die Sterne der Familie.

## Der Familien-Code

Der Familien-Code ist der Schlüssel zu den Sternen eurer Familie. Er hat 16 Buchstaben und Zahlen in 4 Gruppen, zum Beispiel `7K2M-QX9D-4HPT-W3RA`. Kleine und große Buchstaben gehen beide, mit oder ohne Striche. Der Code hat nie ein O, I, L oder U. Tippst du ein O, I oder L ein, liest loopy 0 oder 1.

Um den Code noch einmal zu sehen, öffne ⚙ **Einstellungen** auf einem Gerät, auf dem der Familien-Sync an ist. Der Code steckt nicht im Sterne-Code, nicht in der Sicherungsdatei und nicht im QR-Code unter Meine Sterne. Darum tritt jedes Gerät selbst bei. Hat kein Gerät den Code mehr, tippe noch einmal auf **Einschalten**. Das macht eine neue Familie mit neuem Code. Dann tritt mit den anderen Geräten bei. Mehr unter [Einstellungen auf der Startseite](/loopy/guide/de/settings/home-settings/).

## Was abgeglichen wird, und was nicht

Der Familien-Sync trägt dasselbe wie ein [Sterne-Code](/loopy/guide/de/stars/move-stars/), für jedes Kind auf dem Gerät.

**Kommt auf jedes Gerät der Familie:**

- Name und Bild jedes Kindes.
- Sterne, Abzeichen, Serien und die Tage-Serie. Die größere Zahl gewinnt, nichts geht verloren.
- Die Antworten für die Seite für Erwachsene, die Letzte-5-Punkte und die Liste für Nochmal versuchen.
- Das Alter eines Kindes, seine Stufen, Vorlesen und sein letztes Spiel. Auch seine Wahl in einem Spiel, etwa die Reihen im Einmaleins-Sprint oder die Wortliste im Rechtschreib-Quiz. Das kommt nur auf ein Gerät, das für dieses Kind noch nichts hat. Ein Gerät mit eigener Wahl behält sie.

**Bleibt auf jedem Gerät:**

- Das Farbthema, **Leichter lesen**, Ton und Sprache. Ein ganz neues Gerät, das noch nichts gewählt hat, übernimmt sie einmal von der Familie.
- Welches Kind gerade spielt.
- Der Familien-Code selbst, und ob loopy auf dem Home-Bildschirm ist.
- Deine E-Mail unter **In Kontakt bleiben**. Sie gehört gar nicht zur Familie.

## Wann abgeglichen wird

- **Die Startseite** holt bei jedem Öffnen neue Sterne von den anderen Geräten. Kam etwas Neues, lädt sie einmal neu, um es zu zeigen.
- **Ein Spiel** schickt seine neuen Sterne kurz nach dem Spielen und wenn du das Spiel verlässt.
- **Ein Gerät, das offen liegt,** holt von selbst auf. Nach 5 Minuten ohne Tippen holt es die neuen Sterne und lädt die Seite einmal neu. Ein Spiel zeigt dann eine neue Aufgabe, Stufe und Sterne bleiben. Solange niemand es berührt, prüft es alle 15 Minuten noch einmal, höchstens eine Stunde lang.
- **Jetzt abgleichen** in ⚙ Einstellungen macht es sofort. Darunter zeigt "Zuletzt abgeglichen um", wann dieses Gerät zuletzt abgeglichen hat.

Es lädt die Seite nie neu, während ein Kind tippt, während ein Feld oder die Einstellungen offen sind oder während loopy im Hintergrund ist. Die Spiele warten nie auf das Internet. Die Sterne werden wie immer zuerst auf dem Gerät gespeichert. Ohne Internet steht in den Einstellungen "Wartet auf Internet", und loopy gleicht ab, sobald es wieder da ist.

## Ist das sicher?

- Alles wird **auf deinem Gerät verschlossen**, bevor es gesendet wird. Nur Geräte mit eurem Familien-Code können es öffnen.
- Der Server hat nur die verschlossene Kopie. Er **kann nichts lesen**: keine Namen, keine Sterne, nichts. Den Familien-Code bekommt er nie.
- **Kein Konto**, keine E-Mail, kein Passwort.
- Eine Familien-Kopie, die 400 Tage niemand gespeichert hat, wird gelöscht.

Halte den Familien-Code geheim, wie einen Hausschlüssel. Wer den Code hat, kann eurer Familie beitreten.

## Ausschalten

- **Ausschalten** beendet den Sync auf diesem Gerät. Die anderen Geräte gleichen weiter ab.
- **Überall ausschalten** (zweimal tippen) löscht die Familien-Kopie auf dem Server. Alle Geräte hören auf abzugleichen.

So oder so bleiben die Sterne auf jedem Gerät.

## Meldungen, die du sehen kannst

Die Zeile unter den Knöpfen vom Familien-Sync sagt, was gerade los ist.

| Da steht | Das heißt |
| --- | --- |
| Zuletzt abgeglichen um 16:20. | Alles gut. Dieses Gerät hat zuletzt um diese Zeit abgeglichen. |
| Wird abgeglichen … | Es gleicht gerade ab. Das dauert einen Moment. |
| Wartet auf Internet. Die Sterne sind auf diesem Gerät sicher. | Kein Internet. loopy gleicht ab, sobald es wieder da ist. |
| loopy erreicht den Sync-Server nicht. Versuche es mit Internet noch einmal. | **Einschalten** oder **Beitreten** kam nicht durch. Prüfe das Internet und tippe noch einmal. |
| Das ist kein Familien-Code. Er hat 16 Buchstaben und Zahlen. | Der Code ist zu kurz oder zu lang. Prüfe ihn auf dem anderen Gerät. |
| Keine Familie hat diesen Code. Prüfe ihn auf dem anderen Gerät. | Ein Buchstabe ist falsch, oder diese Familie wurde überall ausgeschaltet. |
| Die Familien-Kopie wurde auf einem anderen Gerät gelöscht. Schalte aus und dann wieder ein oder tritt neu bei. | Jemand hat auf **Überall ausschalten** getippt. Tippe hier auf **Ausschalten**. Dann starte eine neue Familie oder tritt einer bei. |
| Etwas ist schiefgegangen. Die Sterne sind auf diesem Gerät sicher. | Der Server hat nicht wie erwartet geantwortet. Tippe später auf **Jetzt abgleichen**. |

Egal welche Meldung: Die Sterne auf diesem Gerät werden nie angerührt. Sie werden wie immer zuerst auf dem Gerät gespeichert.
