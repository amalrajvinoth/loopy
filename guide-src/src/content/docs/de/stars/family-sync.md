Auf dem Tablet spielen, auf dem Handy weitermachen. Der Familien-Sync hält die Sterne auf allen Geräten deiner Familie gleich.

Er ist aus, bis ein Erwachsener ihn einschaltet. Dann läuft er von selbst: keine Codes kopieren, keine Dateien speichern.

## Einschalten

1. Öffne auf der Startseite ⚙ **Einstellungen**.
2. Scroll zu **Familien-Sync**.
3. Tippe auf **Einschalten**.

loopy zeigt euren Familien-Code, zum Beispiel `7K2M-QX9D-4HPT-W3RA`, und einen QR-Code.

## Ein weiteres Gerät dazunehmen

Auf dem anderen Handy, Tablet oder Computer:

- **Scanne den QR-Code** mit der Kamera. loopy öffnet sich und fragt "Dieser Familie beitreten?". Tippe auf **Beitreten**.
- **Oder tippe den Code ein:** Öffne ⚙ **Einstellungen**, dann **Familien-Sync**, dann **Mit Code beitreten**. Tippe den Code ein und dann auf **Beitreten**.

Die Sterne von den anderen Geräten kommen hierher, und die Sterne von hier kommen dorthin. Nichts geht verloren: Für jedes Kind gewinnt die größere Zahl, wie bei einem [Sterne-Code](/loopy/guide/de/stars/move-stars/).

Jedes Kind behält seine eigenen Sterne. Gib jedem Kind auf jedem Gerät denselben Namen, damit loopy weiß, wer wer ist.

## Wann abgeglichen wird

- **Die Startseite** holt bei jedem Öffnen neue Sterne von den anderen Geräten. Kam etwas Neues, lädt sie einmal neu, um es zu zeigen.
- **Ein Spiel** schickt seine neuen Sterne kurz nach dem Spielen und wenn du das Spiel verlässt.
- **Ein Gerät, das offen liegt,** holt von selbst auf. Nach 5 Minuten ohne Tippen holt es die neuen Sterne und lädt die Seite einmal neu. Ein Spiel zeigt dann eine neue Aufgabe, Stufe und Sterne bleiben. Solange niemand es berührt, prüft es alle 15 Minuten noch einmal, höchstens eine Stunde lang.
- **Jetzt abgleichen** in ⚙ Einstellungen macht es sofort. Darunter zeigt "Zuletzt abgeglichen um", wann dieses Gerät zuletzt abgeglichen hat.

Es lädt die Seite nie neu, während ein Kind tippt, während ein Feld oder die Einstellungen offen sind oder während loopy im Hintergrund ist. Die Spiele warten nie auf das Internet. Die Sterne werden wie immer zuerst auf dem Gerät gespeichert. Ohne Internet steht in den Einstellungen "Wartet auf Internet", und loopy gleicht ab, sobald es wieder da ist.

## Ist das sicher?

- Alles wird **auf deinem Gerät verschlossen**, bevor es gesendet wird. Nur Geräte mit eurem Familien-Code können es öffnen.
- Der Server hat nur die verschlossene Kopie. Er **kann nichts lesen**: keine Namen, keine Sterne, nichts. Den Familien-Code bekommt er nie.
- **Kein Konto**, keine E-Mail, kein Passwort.
- Eine Familien-Kopie, die 400 Tage niemand gespeichert hat, wird gelöscht.

Halte den Familien-Code geheim, wie einen Hausschlüssel. Wer den Code hat, kann eurer Familie beitreten.

## Ausschalten

- **Ausschalten** beendet den Sync auf diesem Gerät. Die anderen Geräte gleichen weiter ab.
- **Überall ausschalten** (zweimal tippen) löscht die Familien-Kopie auf dem Server. Alle Geräte hören auf abzugleichen.

So oder so bleiben die Sterne auf jedem Gerät.
