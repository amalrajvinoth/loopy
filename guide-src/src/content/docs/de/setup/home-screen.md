Hol dir loopy auf den Home-Bildschirm. Dann tippst du auf den Hasen und spielst!

loopy kann sich im Vollbild öffnen, wie eine App, und geht auch offline. loopy zeigt dir die richtigen Schritte für dein Gerät.

## So fängst du an

1. Tippe auf der Startseite auf ⚙ **Einstellungen**.
2. Ganz unten, unter **Wie eine App nutzen**, tippe auf **loopy zum Home-Bildschirm hinzufügen**. Auf dem Computer steht dort **loopy auf diesem Computer installieren**.
3. In Chrome, Edge und Samsung Internet kann sich das Installieren-Fenster des Browsers öffnen. Tippe auf **Installieren**.
4. Sonst zeigt loopy drei Schritte für dein Gerät. Sie stehen auch hier unten.

Der Knopf ist weg, wenn loopy schon vom Home-Bildschirm aus läuft.

## iPhone und iPad (Safari)

1. Tippe auf **Teilen**. Beim iPhone ist es unten in Safari (siehst du nur ···, tippe zuerst darauf). Beim iPad ist es oben rechts, neben der Adresse.
2. Scrolle nach unten und tippe auf **Zum Home-Bildschirm**.
3. Tippe auf **Hinzufügen**.

## Android

- **Chrome:** Tippe oben rechts auf das Menü ⋮, dann auf **Zum Startbildschirm hinzufügen** oder **App installieren**, dann auf **Installieren** oder **Hinzufügen**.
- **Samsung Internet:** Tippe unten rechts auf das Menü ≡, dann auf **Seite hinzufügen zu**, dann auf **Startbildschirm**, dann auf **Hinzufügen**.
- **Firefox:** Tippe auf das Menü ⋮, dann auf **Zum Startbildschirm hinzufügen** (es kann unter **Mehr** stehen), dann auf **Hinzufügen**.

## Mac mit Safari

1. Klicke in Safari oben auf **Teilen** oder in der Menüleiste auf **Ablage**.
2. Klicke auf **Zum Dock hinzufügen**.
3. Klicke auf **Hinzufügen**. Jetzt öffnest du loopy im Dock.

## Computer mit Chrome oder Edge

1. Klicke rechts in der Adressleiste auf das Installieren-Symbol.
2. Kein Symbol? Öffne das Browser-Menü ⋮ oder ··· und suche **Installieren** oder **Apps**.
3. Klicke auf **Installieren**. loopy öffnet sich in einem eigenen Fenster.

## Firefox auf dem Computer

Firefox kann auf dem Computer keine Websites als App hinzufügen. Drücke **Strg+D** (**⌘+D** auf dem Mac), um loopy als Lesezeichen zu speichern. Oder öffne loopy in Chrome, Edge oder Safari.

## iPhone, iPad und Mac: Sterne mitnehmen

Auf Apple-Geräten hat das neue loopy auf dem Home-Bildschirm eigene Sterne, getrennt von Safari. Gibt es Sterne zum Mitnehmen, zeigt das Fenster mit den Schritten auch deinen Sterne-Code.

1. Tippe neben dem Code auf **Kopieren**.
2. Öffne loopy vom Home-Bildschirm.
3. Öffne unter **Meine Sterne** den Punkt **Sterne auf ein anderes Gerät bringen**.
4. Füge den Code ein und tippe auf **Laden**.

Siehe [Sterne umziehen](/loopy/guide/de/stars/move-stars/).
