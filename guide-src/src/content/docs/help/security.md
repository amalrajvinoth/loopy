Found something unsafe? Tell a grown-up. Keep it secret for now.

If you find a security problem in loopy, please report it privately. **Do not post it in a public issue or discussion.**

## Report it privately

1. Open [loopy's security page on GitHub](https://github.com/amalrajvinoth/loopy/security/advisories/new). You need a GitHub account.
2. Say what the problem is.
3. Say where it is: which page or file.
4. Write how to see it happen, step by step.
5. Send it.

Only the owner can see your report. The aim is to reply within 7 days. You hear back when it is fixed, and you are thanked by name if you want.

The same link is on loopy's Help page, under **Report a security problem**.

## What loopy does to stay safe

- **No personal data.** No accounts, no ads, no tracking, no analytics. Stars and settings stay on your device.
- **Nothing from other sites.** Fonts and every file come from the loopy site itself. The page never sends data anywhere.
- **A strict security policy.** Each page tells the browser to load files only from loopy and to run only its own code.
- **No outside code.** loopy uses no libraries or packages.
- **Checked data.** Saved settings and stars codes are checked before use. Nothing in a code is ever run. Child names are plain text, at most 12 letters.
- **HTTPS only.** The site is always served over a secure connection.
- **Reviewed changes.** Every change is reviewed by the owner before it goes live.

Only the live site is supported. For more, read [SECURITY.md](https://github.com/amalrajvinoth/loopy/blob/main/SECURITY.md).
