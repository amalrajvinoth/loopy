Ask a grown-up to open loopy. Then pick a game and play!

loopy is a website. There is nothing to download or install, and no sign-up.

## The address

Type this into the address bar of the browser:

`amalrajvinoth.github.io/loopy`

The full address is `https://amalrajvinoth.github.io/loopy/`.

## On a phone or tablet

1. Open the browser: Safari on an iPhone or iPad, Chrome or Samsung Internet on Android.
2. Type the address and open it.
3. The home page shows the games. Tap one to play.

Tip: add loopy to the home screen, so it opens like an app. See [Add to the home screen](/loopy/guide/setup/home-screen/).

## On a computer

1. Open Chrome, Edge, Firefox or Safari.
2. Type the address and open it.
3. Click a game, or use the keyboard: **Tab** moves between buttons and **Enter** picks one.

Every game works with a keyboard alone. Number keys type into the number pad.

## Which browsers

loopy works in the browser the device already has. These are the ones it knows by name: Safari, Chrome, Edge, Firefox and Samsung Internet. Use an up-to-date version.

A private window works, but the stars go away when it is closed. Use a normal window to keep them.

## After the first visit

loopy keeps a copy of itself on the device. Next time it opens fast, even with no internet. See [Works offline](/loopy/guide/setup/offline/).
