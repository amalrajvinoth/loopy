No internet? You can still play!

## After one visit

Open loopy once with internet. The browser then keeps a copy of the whole site on the device: every page, script, font and icon. From then on loopy opens from that copy, online or not.

It works on a plane, in the car, or anywhere with no signal. Every game works offline, and so do Today's 10, the Help page and the grown-ups' page.

There is nothing to switch on. It happens by itself.

## It updates by itself

1. When you are online, loopy checks for a new version when it opens, at least once a day.
2. If there is one, it downloads only the files that changed.
3. The next page you open shows the new version.

So a child always plays one whole version of the site, never half old and half new. See [What's new](/loopy/guide/help/whats-new/) for the changes.

## Good to know

- Stars are saved on the device, so they work offline too.
- Add loopy to the home screen, so it is one tap away. See [Add to the home screen](/loopy/guide/setup/home-screen/).
- If you clear the browser's data, the saved copy goes too. Open loopy once with internet to get it back. Clearing the data also removes the stars, so keep a backup. See [Backup file](/loopy/guide/stars/backup-file/).
