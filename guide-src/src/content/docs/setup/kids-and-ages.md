Brothers and sisters can share one device. Each one gets their own stars!

## One child to start

A new device starts with one child and shows no name. That is all you need for one child. Set the age in ⚙ **Settings** with **−** and **+**.

## Add a child

1. On the home page, tap ⚙ **Settings**.
2. Under **Kids**, tap **Add a child**.
3. Type a **Name**. A nickname is fine. It can be up to 12 letters.
4. Pick a **Picture**: one of 12 animals.
5. Set the **Age** with **−** and **+**, from 5 to 16.
6. Tap **Save**.

You can add up to 6 children on one device.

## Who is playing?

With two or more children, **Who is playing?** shows at the top of the home page. Tap a name to switch. The page opens again for that child.

In a game, the child's picture and name sit next to ⚙ **Settings**, so everyone can see whose turn it is.

## What each child has

Each child has their own stars, badges, streaks, age, game levels, game settings, **Try again** list and last game. The color theme, the sound and the language are the same for everyone on the device.

## Change or remove a child

1. In ⚙ **Settings** on the home page, tap the child under **Kids**.
2. Change the name or the picture and tap **Save**.
3. To remove the child, tap **Remove**, then tap it again to be sure.

Removing a child deletes their stars on this device. The last child cannot be removed. When only one child is left, the names hide again.

## Ages

The age picks where each game starts: easier for younger children, harder for older ones. Change it any time with **−** and **+** in ⚙ **Settings**, on the home page or in a game. Each game keeps its own level for each age. See [Levels](/loopy/guide/playing/levels/).

The age goes up by one by itself once a year, at the start of August, so you rarely need to change it.
