Every game has steps, from easy to hard. Climb one step at a time!

Each game card on [the grown-ups page](/loopy/guide/grown-ups/grown-ups-page/) starts with a level line. It uses the same words as the game itself.

## How to read it

Take "Level 3 of 5 · Every 5 min":

- **3** is the step the child is on now.
- **of 5** is how many steps the game has.
- **Every 5 min** is the name of that step.

"▲ went up this week" or "▼ a bit easier this week" shows when the level moved in the last 7 days. It compares with the last time this page was opened.

The age picks the start level. A level is kept for each age and each child. The page only reads the level. It never changes a game's settings. To change a level, use the game's ⚙ Settings. See [Levels](/loopy/guide/playing/levels/).

**Ready for more** names the next step, like "Try the next level: Every minute". A game on its top step is not offered.
